# Screenshot shot list — assessment guide

Drop each file in this folder using the EXACT filename below. The guide picks
them up automatically; any that are missing show a labelled placeholder instead,
so the page never looks broken while you're part-way through.

Capture at **1600px wide or more**, PNG. Crop tight to the thing being pointed
at — a full-desktop screenshot shrinks the important part to nothing on a phone.

## Anonymise before you shoot
These go to external candidates. Use a throwaway GitHub account, and check no
real candidate name, email, score or private repo is visible in any frame.

| # | Filename | What to capture |
|---|---|---|
| 1 | `01-install.png` | VS Code Extensions panel, "DevSimulate" searched, Install button visible |
| 2 | `02-ticket.png` | DevSimulate sidebar showing an assigned ticket — title, difficulty, files to investigate |
| 3 | `03-fork-clone.png` | The ticket card with **Fork & Clone** visible (hover state if you can) |
| 4 | `04-editing.png` | The cloned repo open in VS Code, a file being edited. Ordinary coding — no AI panel needed |
| 5 | `05-push-pr.png` | The **Push & Create PR** button, ideally mid-action or with the success toast |
| 6 | `06-submit.png` | The **Submit PR for Review** button — this is the point of no return, so make it unmistakable |
| 7 | `07-writeup.png` | The browser write-up screen showing all four labelled sections |
| 8 | `08-question.png` | A follow-up question screen (Q1 or Q2) with the answer box |
| 9 | `09-verbal.png` | The spoken-explanation screen: camera preview, mic indicator, the question |
| 10 | `10-done.png` | The confirmation screen after finishing |
